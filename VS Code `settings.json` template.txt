A **VS Code `settings.json` template** for enforcing Python formatting centers on two tools widely recommended in authoritative sources: **Black** for code formatting and **isort** for import organization. Both are supported directly by official VS Code extensions, and sources confirm how to configure them in `settings.json` so they run automatically on save   [blog.renewelches.com](https://blog.renewelches.com/2025/11/11/vscode-python-formatter/)  [Visual Studio Code](https://code.visualstudio.com/docs/python/formatting).

Below is a complete, ready‑to‑use configuration plus a clear explanation of how to use it.

---

# **VS Code `settings.json` Template for Python Formatting**

```json
{
    "[python]": {
        "editor.defaultFormatter": "ms-python.black-formatter",
        "editor.formatOnSave": true,
        "editor.codeActionsOnSave": {
            "source.organizeImports": "always"
        }
    },

    "isort.args": ["--profile", "black"]
}
```

---

# **What Each Setting Does**

- **`editor.defaultFormatter`**  
  Sets Black as the formatter for Python files. VS Code documentation confirms this is the correct way to select Black as the default formatter   [Visual Studio Code](https://code.visualstudio.com/docs/python/formatting).

- **`editor.formatOnSave`: true**  
  Automatically formats Python code with Black every time you save the file. This behavior is described in multiple formatting guides, including the VS Code docs and community tutorials   [blog.renewelches.com](https://blog.renewelches.com/2025/11/11/vscode-python-formatter/).

- **`editor.codeActionsOnSave.source.organizeImports`: "always"`  
  Ensures isort runs on every save—including auto‑save. This setting is recommended in community solutions to ensure isort works reliably with auto‑save   [Stack Overflow](https://stackoverflow.com/questions/76460576/how-to-make-black-and-isort-work-with-auto-save-on-vscode).

- **`isort.args`: ["--profile", "black"]**  
  Configures isort to use Black‑compatible formatting, preventing conflicts between the two tools. This configuration is recommended in authoritative formatting guides   [blog.renewelches.com](https://blog.renewelches.com/2025/11/11/vscode-python-formatter/).

# **How to Use This Template in VS Code**

## **1. Install Required Tools**
Install the Python packages:

```bash
pip install black isort
```

This installation step is confirmed in multiple setup guides for Black and isort in VS Code   [blog.renewelches.com](https://blog.renewelches.com/2025/11/11/vscode-python-formatter/).

## **2. Install the VS Code Extensions**
Search for and install:

- **Black Formatter**  
- **isort**

These are the official extensions listed in the VS Code documentation for Python formatting and import sorting   [Visual Studio Code](https://code.visualstudio.com/docs/python/formatting).

## **3. Open Your `settings.json`**
VS Code’s documentation explains how to open the JSON settings file:

1. Press **Ctrl + ,** (Windows/Linux) or **Cmd + ,** (Mac).  
2. Click the **Open Settings (JSON)** icon in the top‑right corner.  
3. Paste the template into your `settings.json`.

  [youtube.com](https://www.youtube.com/watch?v=cG88P-MsdzQ)



## **4. Save Any Python File**
Now, every time you save:

- Black reformats your code.
- isort organizes your imports.
- Both tools stay consistent because isort uses Black’s profile.

This behavior is confirmed in formatting guides and tutorials that demonstrate Black and isort running automatically on save in VS Code   [blog.renewelches.com](https://blog.renewelches.com/2025/11/11/vscode-python-formatter/).
