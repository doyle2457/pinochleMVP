This gives the game engine access to:

Why this pattern is ideal for your design
The GUI doesn’t need to know game rules

The game doesn’t need to know PyQt internals

The UI object (self.ui) gives the game access to the label positions

You avoid circular imports

You avoid mixing logic with presentation

This is the cleanest separation of concerns
